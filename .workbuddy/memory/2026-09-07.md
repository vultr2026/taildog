# 2026-09-07

## 修复 Android 端 Copy / Copy link 不生效 (→ v0.4.1)
- 根因：WritePanel 的 `onCopy`/`onCopyLink` 直接用 `navigator.clipboard.writeText()`。Android Capacitor WebView 即使 `androidScheme:"https"`（origin=`https://localhost`，属 secure context，`navigator.clipboard` 存在），WebView 未获 clipboard-write 能力，`writeText` 抛 `NotAllowedError` 或静默失败 → catch 显示 "Copy failed"，剪贴板实际无内容。Web 浏览器侧正常，仅 APK 坏。
- 修复：安装 `@capacitor/clipboard@^8` (v8.0.1，匹配 Capacitor 8)；新增 `web/src/lib/clipboard.ts` 的 `copyText()`：native 走 `Clipboard.write`（Android `ClipboardManager`），web 走 `navigator.clipboard.writeText`（secure context 守卫），最后回退 `execCommand('copy')` 文本域选择。`write-panel.tsx` 两处改为调用 `copyText`。
- 版本：`web/package.json`、`server/package.json` → `0.4.1`；`android/app/build.gradle` `versionName "0.4.1"`、`versionCode 5`。
- 构建：`npm run typecheck` 通过 → `npm run build`（dist 0.4.1）→ `npx cap sync android`（clipboard 插件已注册）→ `gradlew assembleDebug`（JDK21 + gradle 8.14.3 缓存）BUILD SUCCESSFUL，`:capacitor-clipboard:assembleDebug` 已编译。
- 产物：`release/taildog-app-debug-0.4.1.apk`（4.2MB，`com.taildog.app` vc5/vn0.4.1）。已删除被取代的 0.4.0 APK。`release/` 现仅留 0.3.1、0.4.1。
- 注意：reader-view.tsx 仍 `document.addEventListener("copy", block)` 阻止复制解密正文（隐私设计，非本次问题）。
